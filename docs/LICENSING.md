# Licensing and attribution

This repository uses a permissive hardware license together with separate documentation and tooling licenses. The complete texts are bundled locally; this scope map explains which one to read for each part of the project.

| Material | License | Full text |
| --- | --- | --- |
| Supplied hardware files under `hardware/` | CERN-OHL-P-2.0 | [CERN Open Hardware Licence, permissive variant](../LICENSES/CERN-OHL-P-2.0.txt) |
| Original English documentation, original SVG, inventory and citation metadata | CC-BY-4.0 | [Creative Commons Attribution 4.0](../LICENSES/CC-BY-4.0.txt) |
| Python/PowerShell scripts, Windows launcher, GitHub workflow code | MIT | [MIT license](../LICENSES/MIT.txt) |
| External article, figures, standards and software | Their respective terms | Consult the original source |

The [top-level LICENSE](../LICENSE) is the authoritative map for this repository's grants. Original hardware files were preserved without inserting headers; their directory placement supplies the applicable scope. License texts themselves retain their original notices.

When redistributing or adapting the project, retain applicable notices and license texts, credit **Tsinghua KB Magnet Open Source contributors**, and identify your modifications. Credit the article's authors for the scientific work using the provided citation. Do not describe the article's authors as authors of a CAD revision unless that authorship is independently established.

The publisher applies these grants to the supplied project within the rights they control. Institution names, software names, and standard identifiers describe the source context; no trademark or institutional endorsement is implied. The article is linked rather than included and is not covered by the repository's licenses.

For official license context, see [CERN's Open Hardware Licence resources](https://cern-ohl.web.cern.ch/) and [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). The bundled full texts govern reuse.
